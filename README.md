# Solvanta

Solvanta provides small, free browser-based tools for everyday tasks. The main live pages are `/`, `/tools/`, `/about/`, and `/contact/`.

Current utilities are the message builder, text cleaner, and percentage helper. Their processing runs locally in the browser; they do not transmit typed tool inputs or save them.

Course content was retired from the public site in November 2026 and remains recoverable through Git history. Legacy certificate verification is intentionally retained at `/verify/`.

## Hosting

Static HTML, CSS, and JavaScript on GitHub Pages. No build step. Configure the contact and certificate backend via `assets/js/config.js` and the external Google Apps Script deployment.

## Validation

Check `/tools/` with desktop and mobile widths; try each utility, copying output, page links, and keyboard navigation. For previous certificates, verify known IDs against the actual backend before making verification claims.
