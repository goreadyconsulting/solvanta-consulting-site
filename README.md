# Solvanta\n\nSolvanta provides small, free browser-based tools for everyday tasks. The main live pages are `/`, `/tools/`, `/about/`, and `/contact/`.\n\nCurrent utilities are the message builder, text cleaner, and percentage helper. Their processing runs locally in the browser; they do not transmit typed tool inputs or save them.\n\nCourse content was retired from the public site in November 2026 and remains recoverable through Git history. Legacy certificate verification is intentionally retained at `/verify/`.\n\n## Hosting\n\nStatic HTML, CSS, and JavaScript on GitHub Pages. No build step. Configure the contact and certificate backend via `assets/js/config.js` and the external Google Apps Script deployment.\n\n## Validation\n\nCheck `/tools/` with desktop and mobile widths; try each utility, copying output, page links, and keyboard navigation. For previous certificates, verify known IDs against the actual backend before making verification claims.\n
